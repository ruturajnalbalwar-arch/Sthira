# Sthira

Strength and balance checks for older adults with just a phone camera, even under a saree or dhoti.

Sthira is a browser app that home physiotherapists use to run three standard tests from the US CDC's STEADI toolkit: the 30-second chair stand, the 4-stage balance test and the Timed Up-and-Go. It records results over time and keeps track of home exercise.

Built for **HABIT Idea Diffusion 2026** (HABIT Foundation, VES). Finale: 31 Oct 2026.

## What the prototype must show on 31 Oct

- **Live:** the chair-stand counter. It counts a stand only when the head rises close to the person's own calibrated standing height, so it still works when clothing hides the knees.
- **Early modules:** balance sway and the Timed Up-and-Go timer.
- **Physiotherapist dashboard** and a sample weekly family report.

Sthira shows functional scores next to CDC reference norms (US data). The physiotherapist interprets them. It does not diagnose or predict falls.
